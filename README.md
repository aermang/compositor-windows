# Compositor for Windows

## 1. 项目简介

一个 Photoshop 风格的图层式图像编辑器，macOS 原生应用 **Compositor** 的 Windows 版。

- macOS 原版使用 Swift/AppKit 编写（约 36k 行，源码位于上级目录 `../`）。本项目**不是逐行移植**，而是用 Web 技术栈重写，在关键路径上保持**像素级行为对齐**（混合模式、调整层算法、图层效果等）。
- **格式互通**：读写与 macOS 版完全相同的 `.comp` 项目格式——文件夹包：`manifest.json` + `images/<UUID>.png`，版本号 11。两个平台可互相打开并继续编辑同一项目。

## 2. 技术栈

| 层 | 技术 |
|---|---|
| 前端 | Vue 3 + TypeScript + Vite |
| 渲染引擎 | Canvas 2D；24 种 Photoshop 混合模式（16 种直接映射 canvas `globalCompositeOperation`，其余 8 种逐像素计算回退） |
| 桌面壳 | Tauri 2（WebView2） |
| 文件 IO | Rust 自定义命令（读写 `.comp` 包、图片导入导出等） |
| 原生对话框 | tauri-plugin-dialog |

## 3. 运行与打包

```bash
pnpm install        # 安装依赖
pnpm tauri dev      # 开发模式（前端热更新 + Rust 壳）
pnpm tauri build    # 打包正式版安装包
pnpm build          # 仅前端：类型检查 + 打包
```

环境要求：**Node 20+**、**pnpm**、**Rust toolchain**（stable）、**WebView2**（Windows 10/11 一般已内置）。

## 6. v2 未包含（相对 macOS 版）

- 修复画笔（healing brush）
- 快捷键自定义
- 主体选取 / 对象选取的机器学习模型（macOS 版用 Vision 框架）——本版以纯算法近似（边缘条带 k-means + Otsu + 导向滤波精修），复杂背景下的准确度不及原版
- Camera Raw 的 763 个查找表以公式近似，极端参数下与原版有可感知偏差

## 7. 已知限制

- 画布类滤镜（高斯模糊、暗角、泛光、锐化）作用于**整层**而非当前选区。
- 填充 / 清除操作：仅当图层尺寸与画布尺寸一致时，选区遮罩才与像素精确对应；一般变换图层上剪切/漂浮/清除的选区映射是重采样近似。
- 文字渲染依赖 WebView2 的系统字体，而非 macOS 的 CoreText，同一字体跨平台渲染可能存在细微差异；内联编辑器的行盒度量与画布 textBaseline 只是近似对齐。
- PSD 蒙版按图层左上角对齐导入（记录未携带蒙版矩形），蒙版与图层边界不一致时可能有偏移（导入说明会提示）；levl 字节序未经真实 PSD 全量回归。
- 漂浮选区 / 变换选区内容：源图层带旋转/缩放时，选区像素映射经重采样，边缘有细微误差。
- 切换文档标签页会重置撤销历史（每个文档的历史不跨标签保留）。
- 模糊笔刷的模糊快照按整层生成，超大图层上起笔有一次性的快照开销。
- 多文档标签页的视图快照在窗口 resize 后不重算（恢复时按原比例居中近似）。
